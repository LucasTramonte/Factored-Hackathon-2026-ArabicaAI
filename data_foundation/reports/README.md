# Evidence reports

The earlier Marketing/Product report and the separate time-series dashboard have been withdrawn. They were generated by CSV readers before the Bronze/Silver pipeline was integrated. Their source-date, product-link and population assumptions need revalidation, so the old HTML and JSON are no longer published here.

The next report will be rebuilt from verified `silver.dim_*` and `silver.fact_*` tables. See the [deferred analysis plan](../../Docs/Plans/marketing-product-trust.md) for the decision questions, required denominators and release gate. To reproduce the current data-quality gate, follow [REPRODUCIBILITY.md](../../REPRODUCIBILITY.md).

No Marketing or Product outcome claim is approved for reuse from the withdrawn reports.
