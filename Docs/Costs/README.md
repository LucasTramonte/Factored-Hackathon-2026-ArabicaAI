# Cost evidence

Everything about cost, sizing and where each layer runs is proposed and explained in **[ADR-004](../ADRs/ADR-004-intake-capacity-and-cost.md)** (Proposed). This folder only holds the evidence it cites.

| File | What it is |
|---|---|
| [`Intake/aws-pricing-calculator-2026-09-30.csv`](Intake/aws-pricing-calculator-2026-09-30.csv) | Export of the AWS production-target estimate: $86.36 a month, US East (Ohio), list price, free tier not applied. Public link: [calculator.aws](https://calculator.aws/#/estimate?id=2c6fd3cd749c39840166f0e274fd6813501f5f7e). Each line's description gives its sizing and source |
| [`aws-target/architecture.yaml`](aws-target/architecture.yaml), [`aws-target/edge-us-east-1.yaml`](aws-target/edge-us-east-1.yaml) | The AWS production target as CloudFormation (main stack in us-east-2, WAF stack in us-east-1), **design only, never deployed**. Both pass `cfn-lint`. The diagram, [`aws-target/architecture.png`](aws-target/architecture.png) (SVG source generated by `aws-target/build_diagram.py`), shows the same design |
| [`gcp-target/main.tf`](gcp-target/main.tf) | The same production target on Google Cloud as Terraform, **design only, never applied**. Passes `terraform validate`. Priced line by line at $90.09 a month from the Cloud Billing Catalog's list prices (us-central1, read 2026-10-04) in [`gcp-target/README.md`](gcp-target/README.md), with its diagram generated by `gcp-target/build_diagram.py` |
| [`Intake/INTAKE_COST_ESTIMATE.xlsx`](Intake/INTAKE_COST_ESTIMATE.xlsx) | Cloudflare capacity and cost workbook for the prototype, generated by `scripts/intake_cost/build_workbook.py`. It models the legacy `/cases` flow; the guided flow's capacity is in ADR-004 section 2 |

Figures are pre-tax USD. The calculator doesn't check credits or free-plan eligibility for any account.
